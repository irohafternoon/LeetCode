#### 考えたこと
- 利益の最大化なので、今日の価格が翌日から上がった場合にその差を足し合わせていけば良い


計算量
- 時間計算量　C++の計算ステップを　10^9回/秒と見積もって N = 3 * 10^4の時　30マイクロ秒と見積もり
- 空間計算量　O(1)

```cpp
#include <vector>

class Solution {
 public:
  int maxProfit(const std::vector<int>& prices) {
  	if(prices.empty()) {
  		return 0;
  	}
    int max_profit = 0;
    for (int i = 1; i < prices.size(); i++) {
      if (prices[i] > prices[i - 1]) {
        max_profit += prices[i] - prices[i - 1];
      }
    }
    return max_profit;
  }
};
```

-　山で売って谷で買うを繰り返すと、最終的な取引回数を最小化できる

- 各時点での持っている「お金の最大値」を記録する
	- 状態は「株を持っている」「株を持っていない」の２つ
	- 遷移の種類として「売る」「買う」「何もしない」「売ってから買う」がある、「売ってから買う」はお金にインパクトも与えないので、ないものと考えて良い
	- formatterに通した時、変数 = のところで改行してなるほどとなった
```cpp
#include <algorithm>
#include <vector>

class Solution {
 public:
  int maxProfit(const std::vector<int>& prices) {
    if (prices.empty()) {
      return 0;
    }
    int cash_by_holding = -1 * prices[0];
    int cash_by_selling = 0;
    for (int i = 1; i < prices.size(); i++) {
      int cash_by_holding_today =
          std::max(cash_by_holding, cash_by_selling - prices[i]);
      int cash_by_selling_today =
          std::max(cash_by_selling, cash_by_holding + prices[i]);
      std::swap(cash_by_holding, cash_by_holding_today);
      std::swap(cash_by_selling, cash_by_selling_today);
    }
    return cash_by_selling;
  }
};
```
- 山で売って谷で買う、を繰り返す方法（取引回数の最小化）

```cpp
#include <vector>

class Solution {
 public:
  int maxProfit(const std::vector<int>& prices) {
    if (prices.empty()) {
      return 0;
    }
    int cash = 0;
    int day_i = 0;
    while (day_i < prices.size()) {
      // 　谷を探す
      while (day_i + 1 < prices.size() && prices[day_i] >= prices[day_i + 1]) {
        ++day_i;
      }
      // 　下り坂の途中で最終日になったら、買わなくて良い
      if (day_i == prices.size() - 1) {
        break;
      }
      // 　谷で買う
      cash -= prices[day_i];
      // 　山を探す
      while (day_i + 1 < prices.size() && prices[day_i] <= prices[day_i + 1]) {
        ++day_i;
      }
      // 　山で売る（登りの途中で最終日が来ても売る）
      cash += prices[day_i];
    }
    return cash;
  }
};
```
- ↑のコードは動くが、whileの()何の条件で止まることはない、なぜならday_iがprces.size() - 1 を超えることがないため
	- 常にif (day_i == prices.size() - 1)の箇所でbreakされて止まる

- 以下のように外側のwhileループの最初で、最終日であれば終了するという方法にして、コメントで補足するのがいいだろうか
	- 山と谷でそれぞれ最終日になるか判定してbeakする方法もあるが、かなりコードが見辛くなりそう
