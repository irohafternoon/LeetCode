# 98. Validate Binary Search Tree
https://leetcode.com/problems/validate-binary-search-tree/

## STEP1
- 何も見ずに解いてみる

#### 考えたこと
- ノードの満たすべき条件は、自分の左の子が自分より小さく、自分より右の子が自分より大きいことである。
- よって、node->valが満たすべき範囲をleft, rightの引数で持っていき、再帰的に判定する
- ただ、値がint型のすべての値を取り得るため、left right をlong long(64ビット整数)で取る必要があると思った


計算量
- 時間計算量 O(N) 頂点と枝で3Nステップ　N = 10^4の時 3 * 10^4ステップ　30マイクロ秒と見積もり
- 空間計算量 O(N)


```cpp
#include <climits>

class Solution {
public:
    bool isValidBST(TreeNode* root) {
        return isValidBSTHealper(root, LLONG_MIN, LLONG_MAX);
    }
private:
    bool isValidBSTHealper(TreeNode* node, long long left_limit, long long right_limit) {
        if (!node) {
            return true;
        }
        if (!(left_limit < node->val && node->val < right_limit)) {
            return false;
        }
        if (!isValidBSTHealper(node->left, left_limit, node->val) ||
            !isValidBSTHealper(node->right, node->val, right_limit)) {
            return false;
        }
        return true;     
    }
};
```

pre-order 再帰 LLONG_MAXを使わずにポインタを使用する方法

- 基本的に値の比較はnode->val同士（int型内）で行われるはず
- なので、left-rightはポインタの形で持って、node->val同士を比較すればいい
- ただ、左右の番兵は必要なので、それを双方nullptrとして扱う。nullptrとの比較は問答無用でOKとすれば良い

```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        return isValidBSTHealper(root, nullptr, nullptr);
    }
private:
    bool isValidBSTHealper(TreeNode* node, TreeNode* left_limit_node, TreeNode* right_limit_node) {
        if (!node) {
            return true;
        }
        if (left_limit_node && !(left_limit_node->val < node->val)) {
            return false;
        }
        if (right_limit_node && !(node->val < right_limit_node->val)) {
            return false;
        }
        return isValidBSTHealper(node->left, left_limit_node, node) &&
               isValidBSTHealper(node->right, node , right_limit_node);
    }
};
```

pre-order 非再帰
```cpp
#include <climits>
#include <vector>

class Solution {
public:
	bool isValidBST(TreeNode* root) {
		std::queue<std::tuple<TreeNode*, long long, long long>> nodes_and_ranges;
		nodes_and_ranges.emplace(root, LLONG_MIN, LLONG_MAX);
		while (!nodes_and_ranges.empty()) {
			auto [node, left_limit, right_limit] = nodes_and_ranges.front();
			nodes_and_ranges.pop();
			if (!node) {
				continue;
			}
			if (!(left_limit <= node->val && node->val <= right_limit)) {
				return false;
			}
			nodes_and_ranges.emplace(node->left, left_limit, node->val - 1LL);
			nodes_and_ranges.emplace(node->right, node->val + 1LL, right_limit);
		}
		return true;
	}
};
```

in-order　再帰
- 左部分木を探索　→ 左の帰りがけで、nodeのvalとprev_valueを比較　→ 右部分木を探索　のセットを再帰的に行う
```cpp
#include <climits>  

class Solution {
public:
    bool isValidBST(TreeNode* root) {
        long long prev_value = LLONG_MIN;
        bool result = true;
        IsValidBSTHelper(root, prev_value, result);
        return result;
    }
private:
    void IsValidBSTHelper(TreeNode* node, long long& prev_value, bool& result) {
        if (!node) {
            return;
        }
        IsValidBSTHelper(node->left, prev_value, result);
        if (!(node->val > prev_value)) {
            result = false;
            return;
        }
        prev_value = node->val;
        IsValidBSTHelper(node->right, prev_value, result);
    }
};
```

- in-order 非再帰
- 最初に左にいけるだけ行きながら、スタックにあとで戻ってくるためにnodeを記録する
- 左に行き切ったら、prev_valueとnode->valを比べ、昇順になっていなければfalse;
- 左に行き切ったので、stackにある一番新しいノードに戻る。
- その後、右のノードに行けるなら行き、また左に行けるだけ行く、の繰り返し
	- 右にいけなければ、さらにstackの１つ前のノードに戻る。
- nodeがnullptrの状態で、かつ、もう戻るノードがなければ、終了l。
```cpp
#include <climits>
#include <stack>

class Solution {
public:
	bool isValidBST(TreeNode* root) {
        return IsValidBSTHelper(root);
	}
private:
	bool IsValidBSTHelper(TreeNode* node) {
		long long prev_value = LLONG_MIN;
		std::stack<TreeNode*> nodes_to_visit;
		while (true) {
			while (node) {
				nodes_to_visit.push(node);
				node = node->left;
			}
			if (nodes_to_visit.empty()) {
				break;
			}
			node = nodes_to_visit.top();
			nodes_to_visit.pop();
			if (!(node->val > prev_value)) {
				return false;
			}
			prev_value = node->val;
			node = node->right;
		}
		return true; 
	}
};
```
