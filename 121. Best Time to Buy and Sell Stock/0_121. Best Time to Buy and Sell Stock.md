# 121. Best Time to Buy and Sell Stock
https://leetcode.com/problems/best-time-to-buy-and-sell-stock/description/

## STEP1
- 何も見ずに解いてみる

#### 考えたこと
- 昨日までの最安値と今日の値の差を毎日記録していって、その最大値が答え
- 今日買って今日売るパターンは利益0なので、max_profitの初期値を0にして最大値を取る場合は、考えなくて良い


計算量
- 時間計算量 O(N) N = 10^5ステップの時 10マイクロ秒
- 空間計算量 O(1)

```cpp
#include <algorithm>
#include <vector>

class Solution {
    public: int maxProfit(const std::vector < int > & prices) {
        if (prices.empty()) {
            return 0;
        }
        int max_profit = 0;
        int lowest_price_ever = prices[0];
        for (int i = 1; i < prices.size(); i++) {
            // 昨日までの最安値の今日の値を比べる
            max_profit = std::max(max_profit, prices[i] - lowest_price_ever);
            lowest_price_ever = std::min(lowest_price_ever, prices[i]);
        }
        return max_profit;
    }
};
```

```cpp
#include <iostream>
#include <stdexcept> 
#include <vector>

class Solution {
    public: int maxProfit(const std::vector < int > & prices) {
        if (prices.empty()) {
            return 0;
        }
        int max_profit = 0;
        int highest_price_ever = 0;
        for (int i = prices.size() - 1; i >= 0; i--) {
            if (prices[i] < 0) {
                throw std::invalid_argument("Price cannot be negative");

            if (prices[i] > highest_price_ever) {
                highest_price_ever = prices[i];
                continue;
            }

        }
        return max_profit;
    }
};
```

## STEP3
### 3回ミスなく書く
- 負の数あるなら例外を投げる、最安値の更新があるかで場合分けをする方法で

```cpp
#include <algorithm>
#include <stdexcept>
#include <vector>

class Solution {
    public: int maxProfit(const std::vector < int > & prices) {
        if (prices.empty()) {
            return 0;
        }
        int lowest_price_ever = prices[0];
        int max_profit = 0;
        for (int i = 1; i < prices.size(); i++) {
            if (prices[i] < 0) {
                throw std::invalid_argument("Price cannot be negative");
            }
            if (prices[i] < lowest_price_ever) {
                lowest_price_ever = prices[i];
            }
            max_profit = std::max(max_profit, prices[i] - lowest_price_ever);
        }
        return max_profit;
    }
};
```
