# 102. Binary Tree Level Order Traversal
https://leetcode.com/problems/binary-tree-level-order-traversal/description/

## STEP1
- 何も見ずに解いてみる

#### 考えたこと
- 各階層ごとに処理するので、BFSが使えそう
- 各階層ごとに新しく配列のための箱を作り、左→右の順にノードを見て、答えの箱に直接追加していく。
- 別の箱を作ってから答えの箱に入れると、コピーが発生するので避けた


計算量
- 時間計算量 O(N) 3Nステップ　N = 2000の時　6.0 * 10^3ステップ　6マイクロ秒と見積もり
- 空間計算量 O(N)

```cpp
#include <vector>

class Solution {
public:
    std::vector<std::vector<int>> levelOrder(TreeNode* root) {
        if (!root) {
            return {};
        }
        std::vector<std::vector<int>> level_ordered_tree;
        int current_level = 0;
        std::vector<TreeNode*> current_nodes;
        current_nodes.push_back(root);
        while (!current_nodes.empty()) {
            std::vector<TreeNode*> next_nodes;
            level_ordered_tree.emplace_back();
            for (auto node : current_nodes) {
                level_ordered_tree[current_level].push_back(node->val);
                if (node->left) {
                    next_nodes.push_back(node->left);
                }
                if (node->right) {
                    next_nodes.push_back(node->right);
                }
            }
            std::swap(current_nodes, next_nodes);
            ++current_level;
        }
        return level_ordered_tree;
    }
};

```

- とりあえず無効でも配列に入れる方法
    - この場合は配列が結局空になることがあるため、その場合は配列を削除する必要がある
```cpp
#include <vector>

class Solution {
public:
    std::vector<std::vector<int>> levelOrder(TreeNode* root) {
        if (!root) {
            return {};
        }
        std::vector<std::vector<int>> level_ordered_tree;
        int current_level = 0;
        std::vector<TreeNode*> current_nodes;
        current_nodes.push_back(root);
        while (!current_nodes.empty()) {
            std::vector<TreeNode*> next_nodes;
            level_ordered_tree.emplace_back();
            for (auto node : current_nodes) {
                if (!node) {
                    continue;
                }
                level_ordered_tree[current_level].push_back(node->val);
                next_nodes.push_back(node->left);
                next_nodes.push_back(node->right);
            }
            if (level_ordered_tree[current_level].size() == 0) {
                level_ordered_tree.pop_back();
            } 
            std::swap(current_nodes, next_nodes);
            ++current_level;
        }
        return level_ordered_tree;
    }
};

```
- DFS順でも各階層ごとに左から入れていくこともできそうと思ったが、複雑そうなのでBFSを選択した。

#### STEP1以外の手法と感想
- 再帰関数を使う手法もあるが、N = 2000 で再帰関数の問題はなさそう。
- ただ、探索する順番的にも同じ階層を扱うBFSを採用するのがユーザーにとっても良さそうだ。


DFS順で追加する方法
```cpp
#include <vector>

class Solution {
public:
    std::vector<std::vector<int>> levelOrder(TreeNode* root) {
        std::vector<std::vector<int>> level_ordered_values;
        ContructLeverOrderValues(root, 0, level_ordered_values);
        return level_ordered_values;
    }
private:
    void ContructLeverOrderValues(TreeNode* root, int depth,
                                  std::vector<std::vector<int>>& level_ordered_values) {
        if (!root) {
            return;
        }
        if (depth == level_ordered_values.size()) {
            level_ordered_values.emplace_back();
        }
        level_ordered_values[depth].push_back(root->val);
        ContructLeverOrderValues(root->left, depth + 1, level_ordered_values);
        ContructLeverOrderValues(root->right, depth + 1, level_ordered_values);
        return;
    }
};
```
