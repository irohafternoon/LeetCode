# 198. House Robber
https://leetcode.com/problems/house-robber/


## STEP1
- 何も見ずに解いてみる

#### 考えたこと
- 状態は2つで　その家で盗む　と　その家で盗まない　がある。
- この2つの状態での得た金額の最大値を変数に持って更新していく
- 変数名 gain_by_stealing と　gain_by_not_stealing はあんまり気に入っていない

計算量
- 時間計算量 O(N) N = 100 の時 100ステップ 100ナノ秒と見積もり
- 空間計算量 O(1) 

```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int rob(const std::vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }

        int gain_by_stealing= nums[0];
        int gain_by_not_stealing = 0;
        for (int i = 1; i < nums.size(); i++) {
            int temp = gain_by_stealing;
            gain_by_stealing = std::max(gain_by_stealing, gain_by_not_stealing + nums[i]);
            gain_by_not_stealing = std::max(gain_by_not_stealing, temp);
        }
        return std::max(gain_by_stealing, gain_by_not_stealing);
    }
};
```

#### STEP1以外の手法と感想
- メモ化再帰で書き換える方法。空間計算量がO(N)かかるのと、スタックフレームの関係
	- 今回は制約的には問題ないが、積極的に採用はしなさそう
- 1次元のDP配列を作成する
	- 空間計算量がO(N)かかるが、各家ごとにそれまでの盗める金額の最高額の情報を残せる
		- 家を全ては回れないけど、どこまで行けばどれだけ盗めるか知りたい（反社会的）時には良い選択肢、復元も可能
- 2変数タイプは、空間計算量がO(1)であることが特徴
	- 変数の更新の箇所が読み出にとって若干わかりづらい。メモリの制約が厳しい時は採用

- 総合的には、今回の制約では1次元DPを採用したい

- メモ化再帰
```cpp
#include <algorithm>
#include <vector>
#include <map>

class Solution {
public:
    int rob(const std::vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }

        std::map<int, int> house_to_gain;
        return RobHelper(nums.size() - 1, nums, house_to_gain);
    }
    int RobHelper(int house, const std::vector<int>& nums, std::map<int ,int>& house_to_gain) {
    	if (house == 0) {
    		return nums[0];
    	}
    	if (house == 1) {
    		return std::max(nums[0], nums[1]);
    	}
        if (house_to_gain.contains(house)) {
            return house_to_gain[house];
        }
        house_to_gain[house] = std::max(RobHelper(house - 1, nums, house_to_gain),
                                        RobHelper(house - 2, nums, house_to_gain) + nums[house]);
        return house_to_gain[house];
    }
};
```

- 2変数 two_before_max, one_before_max で2変数
```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int rob(const std::vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }
        if (nums.size() <= 2) {
        	return *std::max_element(nums.begin(), nums.end());
        }

        int two_before_max= nums[0];
        int one_before_max = std::max(nums[0], nums[1]);
        for (int i = 2; i < nums.size(); i++) {
            int temp = one_before_max;
            one_before_max = std::max(one_before_max, two_before_max + nums[i]);
            two_before_max = temp;
        }
        return std::max(two_before_max, one_before_max);
    }
};
```

- 1次元DP

#include <algorithm>
#include <vector>

class Solution {
public:
    int rob(const std::vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }
        int num_houses = nums.size();
        if (num_houses <= 2) {
        	return *std::max_element(nums.begin(), nums.end());
        }

        std::vector<int> house_to_gain(num_houses);
        house_to_gain[0] = nums[0];
        house_to_gain[1] = std::max(nums[0], nums[1]);
        for (int i = 2; i < num_houses; i++) {
        	house_to_gain[i] = std::max(house_to_gain[i - 1], house_to_gain[i - 2] + nums[i]);
        }
        return std::max(house_to_gain[num_houses - 1], house_to_gain[num_houses - 2]);
    }
};
