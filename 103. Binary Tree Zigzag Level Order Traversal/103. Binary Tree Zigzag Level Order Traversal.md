# 103. Binary Tree Zigzag Level Order Traversal
https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/description/

## STEP1
- 何も見ずに解いてみる

#### 考えたこと
- BFSで各階層ごとに答えの配列にノードの値を順に詰める
- ノードの深さに応じて配列をreverseする


計算量
- 時間計算量 O(NlogN) と思われる
    - 半分の階層でソートにlogがかかるため
    - ステップ数は3N * logNとして、 N = 2000の時 6.6 * 10^4 ステップ　66マイクロ秒と見積もり
- 空間計算量 
    - O(N)

```cpp
#include <vector>

class Solution {
public:
    std::vector<std::vector<int>> zigzagLevelOrder(TreeNode* root) {
        if (!root) {
            return {};
        }
        std::vector<std::vector<int>> zigzag_ordered_values;
        int current_level = 0;
        std::vector<TreeNode*> current_nodes;
        current_nodes.push_back(root);
        while (!current_nodes.empty()) {
            std::vector<TreeNode*> next_nodes;
            zigzag_ordered_values.emplace_back();
            for (auto node : current_nodes) {
                zigzag_ordered_values[current_level].push_back(node->val);
                if (node->left) {
                    next_nodes.push_back(node->left);
                }
                if (node->right) {
                    next_nodes.push_back(node->right);
                }
            }
            if (current_level % 2 == 1) {
                reverse(zigzag_ordered_values[current_level].begin(),
                        zigzag_ordered_values[current_level].end());
            }
            current_nodes.swap(next_nodes);
            ++current_level;
            
        }
        return zigzag_ordered_values;
    }
};

```

```cpp
#include <deque>
#include <vector>

class Solution {
public:
    std::vector<std::vector<int>> zigzagLevelOrder(TreeNode* root) {
        if (!root) {
            return {};
        }
        std::vector<std::vector<int>> zigzag_ordered_lists;
        bool right_to_left = false;
        std::vector<TreeNode*> current_nodes;
        current_nodes.push_back(root);
        while (!current_nodes.empty()) {
            std::vector<TreeNode*> next_nodes;
            std::deque<int> current_values;
            for (auto node : current_nodes) {
                if (right_to_left) {
                    current_values.push_front(node->val);
                } else {
                    current_values.push_back(node->val);
                }
                if (node->left) {
                    next_nodes.push_back(node->left);
                }
                if (node->right) {
                    next_nodes.push_back(node->right);
                }
            }
            zigzag_ordered_lists.emplace_back(current_values.begin(),
                                                current_values.end());
            current_nodes.swap(next_nodes);
            right_to_left = !right_to_left;
        }
        return zigzag_ordered_lists;
    }
};
```
