# 53. Maximum Subarray
https://leetcode.com/problems/maximum-subarray/description/

## STEP1
- 何も見ずに解いてみる

#### 考えたこと
- まず思いついたのはDPではなく、累積和を計算しながら、累積和の最低値を覚えながら更新していく方法
    - 以前に区間和が丁度kになる区間の数を数える問題があったが、それの応用
- DPでの方法は DP[i]:subarrayの最後がnums[i]であるときの最大の区間和 とすれば良い
    - 最後にDP配列の最大値を調べる

計算量
- 時間計算量 2つの方法ともO(N) N = 10^5の時　10マイクロ秒
- 空間計算量 累積和の方法はO(1), DPはO(N)
 
累積和を利用する方法
```cpp
#include <algorithm> 
#include <climits>

class Solution {
public:
    int maxSubArray(std::vector<int>& nums) {
        int cumulative_sum = 0;
        int max_subarray_sum = INT_MIN;
        int min_cumulative_sum_ever = 0;
        for (int i = 0; i < nums.size(); i++) {
            cumulative_sum += nums[i];
            max_subarray_sum = std::max(max_subarray_sum, cumulative_sum - min_cumulative_sum_ever);
            min_cumulative_sum_ever = std::min(min_cumulative_sum_ever, cumulative_sum);
        }
        return max_subarray_sum;
    }
};
```
DPを利用する方法
```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int maxSubArray(std::vector<int>& nums) {
        // max_sum_until_index[i] : subarrayの最後がnums[i]であるときの最大の区間和
        std::vector<int> max_sum_until_index(nums.size());
        max_sum_until_index[0] = nums[0];
        for (int i = 0; i < nums.size() - 1; i++) {
            // 遷移は、nums[i + 1]を採用して既存のsubarrayに加えるか、新しくnums[i + 1]から始まるsubarrayにするか
            max_sum_until_index[i + 1] = std::max(nums[i + 1], max_sum_until_index[i] + nums[i + 1]);
        }
        return *std::max_element(max_sum_until_index.begin(), max_sum_until_index.end());
    }
};
```

    - もし、答えとなる区間がどこか知りたいといった場合は、DPだと難しいので、避ける

class Solution {

    int maxSubArray(std::vector<int>& nums) {
        int diff_from_bottom = std::max(nums[0], 0);
        int max_subarray_sum = nums[0];
        for (int i = 1; i < nums.size(); i++) {
            diff_from_bottom += nums[i];
            max_subarray_sum = std::max(max_subarray_sum, diff_from_bottom);

```cpp
#include <algorithm>
#include <vector>
class Solution {
public:
    int maxSubArray(std::vector<int>& nums) {
        std::vector<int> max_subarray_sum_at(nums.size());
        max_subarray_sum_at[0] = nums[0];
        for (int i = 0; i < nums.size() - 1; i++) {
            max_subarray_sum_at[i + 1] = std::max(max_subarray_sum_at[i] + nums[i + 1],
                                                  nums[i + 1]);
        }
        return *std::max_element(max_subarray_sum_at.begin(), max_subarray_sum_at.end());
    }
};
```
